# Аналіз музичних сигналів із використанням методів цифрової обробки та машинного навчання

## Опис проєкту

Курсовий проєкт присвячений цифровій обробці музичних сигналів та аналізу їхніх характеристик із використанням методів машинного навчання.

У програмі реалізовано:
- завантаження та аналіз аудіосигналу;
- розрахунок амплітуди, RMS та енергії;
- швидке перетворення Фур'є (FFT);
- визначення домінуючої частоти;
- низькочастотну фільтрацію Butterworth;
- побудову графіків спектрів і спектрограм;
- вилучення аудіоознак за допомогою openSMILE;
- визначення емоційної категорії музичного сигналу за допомогою навченої моделі;
- порівняння результатів аналізу оригінального та відфільтрованого сигналів.

## Використані технології

- Python
- NumPy
- Librosa
- Matplotlib
- SciPy
- Pandas
- openSMILE
- Joblib
- Scikit-learn

## Структура проєкту

- `main.py` — основна програма;
- `AI_Music/` — файли моделей, скрипти навчання та аналізу;
- `AI_Music/DEAM_data/` — дані для роботи з моделлю;
- графічні файли — результати цифрової обробки сигналу.

## Запуск програми

1. Встановити необхідні бібліотеки.
2. Розмістити аудіофайл `song.wav.wav` у кореневій папці проєкту.
3. Переконатися, що файл навченої моделі та датасет розміщені за відповідними шляхами.
4. Запустити команду:

```bash
python main.py
```

## Призначення

Проєкт демонструє можливості цифрової обробки музичних сигналів та застосування машинного навчання для аналізу емоційних характеристик аудіо.
